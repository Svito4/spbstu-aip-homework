# Задача. Матрица

* **Описание:** реализовать ввод и вывод матрицы целых чисел, размеры матрицы вводятся со стандартного ввода, как и элементы матрицы. Программа должна транспонировать введённую матрицу и выводить её в стандартный вывод.
* **Требования:**
  * матрица должна быть представлена двумерным массивом, то есть указателем на указатель;
  * в программе должны корректно обрабатываться неудачные выделения памяти;
  * программа должна завершаться с кодом возврата 1, если не удалось ввести матрицу;
  * программа должна завершаться с кодом возврата 2, если не удалось выделить память;
  * в остальных случаях – код возврата 0.

### Сборка и запуск
* `make` — сборка
* `make run` — запуск
* `make test` — тесты
